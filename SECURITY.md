# Reporting a vulnerability

Report suspected SDK vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/lexrag/lorebo-sdk/security/advisories/new).

Include the affected package and version, a minimal reproduction, expected and observed behavior, and the potential impact. Use synthetic data; do not include credentials or private knowledge-base content.

Please keep vulnerability details out of public issues and pull requests while maintainers investigate. General usage questions and non-security bugs can use public issues.
